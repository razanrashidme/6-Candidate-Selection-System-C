# Automated Applicant Ranking System

## Project Overview
This project is a **C-based application** that automates the recruitment screening process. It reads applicant data, calculates scores based on GPA and experience, and selects the top candidate for specific majors.

## Key Features
* **Automated Screening:** Processes applicant records from a text file.
* **Scoring Logic:** `Base Score = GPA + Experience` (+10 points for MSc).
* **Filtering:** Selects top candidates for majors (CSC, SWE, InS, CEN).
* **Reporting:** Generates an `Output_Applicants.txt` file with results.

## Technical Highlights
* **Dynamic Memory:** Uses `malloc` for efficient memory management.
* **Pointers & Structs:** Demonstrates low-level data handling.
* **File I/O:** Secure reading and writing of data files.
